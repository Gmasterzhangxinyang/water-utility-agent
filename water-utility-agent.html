2知识库分层设计

class KnowledgeEntry:
    question: str
    answer: str
    source: Literal["raw_qa", "reviewed", "canonical"]

    # 溯源（政府项目必须）
    operator_id: str | None
    source_doc: str | None
    created_at: datetime
    reviewed_at: datetime | None

    # 质量信号
    confidence_score: float
    user_feedback: int
    usage_count: int
  • raw_qa → reviewed：人工审核通过，即进入验证层
  • reviewed → canonical：被引用 N 次 + 无负反馈 + 关联到官方文件，方可晋升权威层

3置信度路由（Sigmoid 独立评分）

M2.7 用 sigmoid 而非 softmax — 独立评分，不强制 winner-takes-all。任一维度低于阈值即升级人工，不做零和竞争。

def route_question(question, retrieved_docs, generated_answer):
    scores = {
        "retrieval_relevance": score_retrieval(question, retrieved_docs),
        "answer_groundedness": score_grounding(generated_answer, retrieved_docs),
        "domain_coverage": check_domain_coverage(question),
    }

    # 任一维度低于阈值 → 升级人工，不强制二选一
    if any(s < THRESHOLD for s in scores.values()):
        return "escalate_to_human"
    return "answer_directly"

知识蒸馏

  • 选项 A：RAG 索引扩充（低成本）

这正是 M2.7 bootstrap 循环的本质。

5政府水务项目特殊要求

01 — 可审计性

最重要

每条答案必须能追溯：哪位专员审核、引用哪条法规、何时更新。合规审计的硬要求。

02 — 准确性

优先于覆盖率

水质、应急、安全类问题宁可升级人工，不给低置信度答案。阈值设置需保守。

03 — 分域管理

知识库隔离

水质监测 / 管网维护 / 用户计费 / 应急预案 / 政策法规，各域置信度阈值和审核流程独立。

04 — 模型选型

数据合规

数据不出境：Qwen2.5-72B / DeepSeek-V3 本地部署。M2.7 可通过 API 调用，需确认合规路径。
